# The October design tables (archived 2026-11-13, roadmap R10)

These were the seed tables of the October design pack: five floors, a 'col' currency and numbers the game no longer uses. They are kept for reference only. The real numbers now live in `tools/balance.py` (all ten floors, read by the monster generator), `tools/gen_economy.py` (Floor 1 in detail) and `tools/gen_monsters.py`.
