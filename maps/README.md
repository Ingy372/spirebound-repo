# maps/

Placeholder maps are generated by script, never drawn by hand:

- `layout_floor1.py` describes Floor 1 (Hearthgate Plains) in Python: towns, roads, camps, the apex spawn, the Pass, the 3-level labyrinth, the boss room and the Floor 2 landing.
- `python3 tools/mapgen.py --check-ids <appearances.dat>` builds `server/data-spirebound/world/spirebound.otbm` (+ spawn, NPC and house files, and `lib/spirebound/world_points.lua`) and preview images in `docs/previews/`.

Real maps (by Jay, a mapper, or another agent) replace these: see `MAP_REQUESTS.md`. Keep the named points in `world_points.lua` working (temple, gates, boss rooms) or update the layout file.
